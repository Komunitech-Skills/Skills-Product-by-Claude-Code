### UI punya "Personal Runtime Secrets" tapi VM kosong — kenapa?

1. **Scope salah:** Personal Runtime Secrets ≠ **Runtime secrets** pada **environment repo** yang dipakai agent. Repo ini memakai environment sumber **Repository** ([8c28e904-c466-11f1-ac31-5e2d0494121f](https://cursor.com/dashboard/cloud-agents/environments/e/8c28e904-c466-11f1-ac31-5e2d0494121f)); `.cursor/environment.json` hanya berisi `install`, tidak mendeklarasikan secret (normal — secret tidak masuk JSON).
2. **Secret harus dilampirkan ke environment tersebut** (tab Runtime secrets / Environment secrets di dashboard environment repo), dengan **nama variabel identik** (case-sensitive): minimal `Ninerouter_key`; untuk gateway `bot_token`; untuk Telegram `tester_bot_token`.
3. **Team vs personal:** bila secret hanya di team environment lain atau personal tanpa binding ke environment ID di atas, pod agent **tidak** menerima injeksi.
4. **Run lama:** secret ditambahkan setelah agent sudah boot → VM yang sedang jalan **tidak** otomatis terisi; **mulai Cloud Agent run baru** setelah secret tersimpan di environment.
5. Agent ini juga meminta penambahan secret lewat flow setup (`add_secrets` untuk nama di atas).
