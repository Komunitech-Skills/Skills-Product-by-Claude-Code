# Ide Konten dari Pujian — Aturan & Pola

## Aturan wajib
1. **Tanpa identitas pelanggan**: jangan tampilkan nama, username, foto profil, atau nomor pesanan. Screenshot
   ulasan harus diburamkan bagian identitasnya.
2. **Kutipan asli, tidak diubah maknanya.** Boleh dipotong dengan "…", tidak boleh ditambah kata.
3. **Tanpa klaim baru** yang tidak ada di ulasan atau tidak diberikan pengguna (mis. "terlaris", "nomor 1",
   halal, BPOM, "menyembuhkan"). Klaim kesehatan/kecantikan dari ulasan jangan dijadikan janji ("hasil tiap orang berbeda").
4. Untuk **iklan berbayar** atau memakai foto/video kiriman pelanggan: sarankan minta izin pelanggan dulu (UU PDP).
5. Angka yang dipakai di konten (mis. "4,8 dari 5", "120+ ulasan") harus sama dengan hasil script dan disebut sumbernya
   ("rating di Shopee per <bulan>"). Jangan membulatkan ke atas.

## Pola ide (pilih 3–5 yang paling cocok dengan pujian teratas)
| Pujian dominan | Ide konten | Format |
|---|---|---|
| Kualitas/awet | "Kata mereka setelah pakai 3 bulan" + close-up detail bahan/jahitan | Carousel IG / video 15 dtk |
| Rasa enak | Reaksi gigitan pertama + kutipan ulasan sebagai teks di layar | Reels/TikTok |
| Kemasan rapi | Proses packing (ASMR) + kutipan "packing rapi, aman sampai" | TikTok/Reels |
| Pengiriman cepat | "Pesan jam 10, dikirim hari ini" (hanya jika benar) + kutipan | Story/WA Status |
| Respons ramah | Perkenalkan admin/tim di balik layar + kutipan | Carousel/Story |
| Pembeli berulang | "Pelanggan yang balik lagi bilang…" kompilasi 3 kutipan | Carousel |
| Sesuai foto | Foto katalog vs foto kiriman pembeli (izin) berdampingan | Carousel |
| Harga sepadan | "Apa yang kamu dapat dengan Rp X" + kutipan "worth it" | Carousel/Story |

## Mengubah keluhan jadi konten edukasi (opsional, 1–2 ide)
Keluhan yang sering muncul karena salah paham adalah bahan konten: keluhan ukuran → video "cara pilih ukuran";
keluhan rasa pedas → "panduan level pedas". Jangan membantah pembeli di konten.

## Format per ide
`<nomor>. <format + platform> — Hook: "<kalimat 3 detik pertama>" — Kutipan: "<kutipan asli>" — CTA: "<ajakan>"`
Untuk rencana posting sebulan penuh, arahkan ke skill `kalender-konten-30hari`; untuk menulis caption lengkap → `caption-sosmed-umkm`.
