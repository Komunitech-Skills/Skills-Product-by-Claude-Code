# Skenario S4 — Input tidak lengkap

**Input pengguna (persis):** "tulisin artikel dong"

**Respons agent (mengikuti SKILL.md §Input & §1 Brief):**

Baik, saya bisa bantu tulis artikelnya — tapi supaya hasilnya pas dan berbasis data yang benar, boleh
dijawab beberapa hal ini dulu (jawab santai aja, boleh singkat):

1. **Topiknya apa?** (mis. tren bisnis, tips usaha, kebijakan pemerintah, dll — sebutkan setopik
   mungkin)
2. **Untuk apa/di mana dipakai?** artikel blog/website, whitepaper, newsletter, atau materi presentasi?
3. **Buat siapa pembacanya?** (mis. calon pelanggan, klien profesional, anggota komunitas)
4. **Kira-kira berapa panjang?** (kalau tidak yakin, saya pakai patokan 800–1200 kata untuk artikel)
5. **Ada sumber/data yang wajib dipakai?** (link, dokumen, atau angka dari Anda sendiri — kalau ada,
   kirim sekalian)

Kalau mau cepat, boleh jawab topiknya saja — sisanya saya pakai asumsi wajar (artikel blog, 800–1200
kata, pembaca umum pengusaha/profesional Indonesia, tujuan edukasi) dan saya sebutkan asumsi itu di
akhir tulisan supaya Anda bisa koreksi kalau meleset.

---

**Catatan penguji:** Ini persis mengikuti aturan §Input SKILL.md ("Jika topik tidak ada, tanyakan
sekali, maks. 5 pertanyaan bernomor"). Pertanyaan singkat, tidak menginterogasi berlebihan, dan
menawarkan jalan cepat (opsi pakai default) sesuai prinsip "instan tapi powerful" di pedoman kurasi Komunitech. Tidak
langsung mengarang topik sendiri, yang tepat karena "artikel dong" benar-benar tidak punya topik sama
sekali (beda dengan kasus di mana topik ada tapi detail lain kurang — di situ default boleh dipakai
langsung).
