# Contoh 4: input tidak lengkap

## Input pengguna
"Bot saya jawabannya sering ngawur. Tolong dinilai." (tanpa percakapan; tanpa tahap)

## Hasil yang diharapkan
Tidak ada angka karangan. Jawaban:

"Supaya bisa saya nilai, saya perlu contoh percakapannya. Caranya mudah: salin 10 sampai 20 percakapan terbaru antara bot dan pelanggan dari chat (teks biasa, tidak perlu rapi), lalu hapus bagian yang berisi nomor kartu, kata sandi, atau data sensitif lainnya. Nama dan nomor yang tertinggal akan saya samarkan di rapor.

Sambil menunggu, ini kerangka rapor yang akan Anda dapat:

| Kriteria | Lolos | Nilai |
|---|---|---|
| Fakta benar | - | - |
| Nyambung | - | - |
| Ingat konteks | - | - |
| Panjang pas | - | - |
| Nada brand | - | - |
| Tidak janji berlebihan | - | - |
| Data pribadi aman | - | - |
| Bebas kata teknis | - | - |

Sebagai tebakan awal untuk bot yang 'sering ngawur', penyebab yang paling sering di bot baru: bot belum diberi daftar harga dan FAQ, sehingga ia menebak. Aturan sementara yang bisa Anda tempel ke catatan bot: 'Jika belum tahu jawabannya, katakan staf akan menghubungi dalam jam kerja; jangan menebak angka, jadwal, atau kebijakan.'

Asumsi: tahap bot belum diketahui, saya anggap minggu 2-4.
(1) Sudah berapa lama bot dipasang? (2) Untuk usaha apa? (3) Apa contoh jawaban ngawur yang paling Anda ingat?"
