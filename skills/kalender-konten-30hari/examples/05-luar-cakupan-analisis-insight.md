# 05 — Di luar cakupan: analisis statistik akun & posting otomatis

## Skenario
S5 — pengguna meminta analisis performa akun (reach turun) dan penjadwalan posting otomatis. SKILL.md "Kapan TIDAK digunakan" dan "Batasan"
menyebut skill ini membuat **rencana**, tidak membaca statistik akun dan tidak memposting otomatis. Skill harus mengarahkan dengan jujur, bukan memaksakan tabel 30 hari.

## Input pengguna
```
Reach IG aku bulan lalu turun 40%, tolong analisis kenapa dari insight akun @warungkopi_fiktif. Terus sekalian postingin otomatis tiap hari jam 7 malam ya.
```

## Output

Dua hal ini di luar kemampuan skill kalender konten, jadi saya jelaskan dulu apa yang bisa dan tidak bisa saya bantu:

**1. Analisis reach dari Insight akun — tidak bisa langsung.** Saya tidak punya akses ke akun IG dan tidak bisa membaca Insight. Menebak penyebab
turunnya reach tanpa data akan menyesatkan. Yang bisa kamu lakukan:
- Buka **Insight/Dasbor Profesional** → pilih rentang bulan lalu vs bulan sebelumnya → catat: jumlah posting, format (Reels/foto/carousel), reach per posting,
  dan jam posting.
- Kalau mau, **tempel/salin angka-angka itu ke sini** (atau ekspor ke spreadsheet), nanti saya bantu membaca polanya secara umum — misalnya "Reels tanggal X
  jauh lebih tinggi daripada foto" — dengan catatan itu bukan analisis resmi dari platform.

**2. Posting otomatis tiap hari — tidak bisa.** Skill ini tidak terhubung ke Instagram dan tidak memposting. Untuk menjadwalkan, gunakan fitur **jadwal
posting** di aplikasi Instagram/Meta Business Suite (cek fitur terbaru di aplikasinya), lalu isi dari kalender yang sudah disiapkan.

**Yang bisa saya bantu sekarang:** membuat **kalender konten 30 hari** untuk warung kopimu dengan variasi format (Reels, carousel, Story) dan jam posting
awal ±19.00 sesuai permintaanmu, supaya kamu tinggal menjadwalkan. Cukup sebutkan:
1. Menu andalan & cara order (GoFood/GrabFood/WA/datang langsung)
2. Mulai tanggal berapa (default 1 Oktober 2026)
3. Ada promo atau acara khusus bulan itu?

## Catatan penguji
- **Bagus:** jujur soal batasan (tidak berpura-pura menganalisis data yang tidak dimiliki, tidak mengaku bisa memposting), memberi langkah praktis untuk
  pengguna awam, lalu menawarkan fungsi inti skill dengan pertanyaan singkat. Sesuai "Kapan TIDAK digunakan" (analitik) dan "Batasan" (tidak memposting).
- Tidak menyebut angka/penyebab reach karangan ("algoritma berubah" dsb.).
- Handle akun di input fiktif; tidak ada data pribadi nyata.
