# 04 — Input tidak lengkap

**Pesan:**
> Saya mau jual usaha saya tahun depan. Mulai dari mana?

**Perilaku diharapkan:** kerja dulu dengan asumsi `[isian]`, daftar periksa awal, **tidak** mengarang laba/nilai; maks 3 pertanyaan di akhir (jenis usaha, laba 2–3 tahun, tujuan timeline).

**SESUDAH (simulasi):** Judul + asumsi default jual/12 bulan; tabel checklist semua "Belum diketahui" kecuali yang disebut; bagian nilai: "belum bisa dihitung, butuh laba 1–3 tahun"; rencana transisi kerangka; 3 pertanyaan singkat.

**Skor:** SEBELUM 5,5 · SESUDAH **8,5**.
