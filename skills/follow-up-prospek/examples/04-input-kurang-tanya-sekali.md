# 04 — Input tidak lengkap (tanya sekali)

**Skenario:** S4 — pengguna hanya bilang prospek ghosting.

**Input pengguna:**
> prospek saya ghosting nih, bikinin follow up dong

## Output

Siap, saya bantu. Supaya pesannya pas dan nggak terkesan mengejar, jawab singkat beberapa hal ini ya:

1. **Terakhir kontak di tahap apa?** (a) sudah kirim penawaran, (b) sudah demo/meeting, (c) dia bilang "nanti dulu", atau (d) cuma tanya harga lalu hilang.
2. **Siapa prospeknya?** Nama (+ perusahaan & jabatan kalau B2B).
3. **Produk/jasa apa & nilai penawarannya** (singkat saja).
4. **Kapan terakhir kontak?** Kalau tidak diisi, saya anggap hari ini.
5. **Kirim lewat WA saja, atau WA + email?** Dan nama Anda sebagai pengirim.

Kalau mau cepat, jawab nomor 1 dan 3 saja — sisanya saya pakai default (WA, mulai hari ini, sapaan "Bapak/Ibu") dan saya tulis asumsinya.

## Catatan penguji
- Sesuai SKILL.md: sekali tanya, 5 pertanyaan bernomor, default jelas.
- Pertanyaan tahap diberi pilihan (a–d) sehingga mudah dijawab orang awam.
