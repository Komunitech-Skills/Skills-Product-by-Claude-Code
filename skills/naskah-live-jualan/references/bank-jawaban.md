# Bank Jawaban Pertanyaan Umum Penonton Live

Pakai sebagai kerangka. Ganti `[...]` dengan data pengguna. Jangan isi data yang tidak diberikan pengguna —
biarkan `[isi: ...]` dan beri tahu pengguna.

Prinsip: sebut nama penonton ("Makasih Kak Rina"), jawab singkat (≤ 2 kalimat), lalu kembali ke CTA.
Jangan pernah minta penonton chat WA/transfer di luar aplikasi.

| Pertanyaan khas di kolom komentar | Kerangka jawaban |
|---|---|
| "Kak, harganya berapa?" / "Hrg?" | "Harga live [harga live] Kak [nama], normalnya [harga normal]. Langsung klik keranjang, produk nomor [n] ya." |
| "Ukuran/size-nya gimana?" / "LD berapa?" | "[ukuran/tabel size]. Kalau ragu, sebut tinggi & berat badan Kakak, saya bantu pilihkan." |
| "Bahannya apa? Panas nggak?" | "[bahan]. [karakter bahan yang diberikan pengguna]. Saya dekatkan ke kamera ya biar kelihatan." |
| "Warna ini ada?" / "Ready?" | "Warna yang ready: [daftar varian]. Yang tidak ada di pilihan varian berarti sedang kosong." |
| "Ori nggak?" / "Aman nggak?" | Jawab hanya dengan fakta pengguna (produksi sendiri, garansi, izin edar + nomor). Jika tidak ada data: "Produk ini [asal produk]; detail lengkap ada di deskripsi produk." |
| "Halal? BPOM?" | Hanya "ya" jika pengguna memberi nomor sertifikat/izin. Jika tidak ada: jangan mengarang, jawab "Untuk info sertifikasi, cek deskripsi produk ya Kak" dan catat untuk pengguna. |
| "Bisa COD?" | "[COD tersedia/tidak sesuai pengaturan toko]. Pilihan pembayaran muncul saat checkout." |
| "Ongkirnya berapa?" / "Gratis ongkir?" | "Ongkir dihitung otomatis sesuai alamat saat checkout. [Voucher gratis ongkir jika memang ada]." |
| "Kapan dikirim?" | "Pesanan dikirim [jadwal kirim pengguna], dari [kota]." |
| "Bisa retur/tukar size?" | "[kebijakan retur pengguna]. Jangan lupa video unboxing ya Kak." |
| "Kok voucher nggak bisa dipakai?" | "Cek minimal belanjanya [min. belanja], dan pastikan klaim voucher di layar live dulu sebelum checkout." |
| "Kak, spill yang itu dong" | "Siap, saya ambil [produk]. [Demo 20 detik]. Nomor keranjang [n]." |
| Komentar negatif/iseng ("mahal amat", "jelek") | Tetap ramah, jangan debat: "Makasih masukannya Kak. Harga segini karena [alasan nyata: bahan/proses]. Ada juga pilihan [produk lebih murah] kalau mau." |
| Pertanyaan medis ("bisa sembuhin jerawat?") | "Kami tidak bisa menjanjikan hasil medis, Kak. Untuk kondisi kulit khusus, sebaiknya konsultasi ke dokter." |
