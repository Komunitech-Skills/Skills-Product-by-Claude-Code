# Template Memo / Surat Edaran Internal

Lebih formal dan "resmi" dibanding pengumuman WA biasa — biasanya untuk kebijakan yang
perlu didokumentasikan (perubahan SOP, aturan baru, penunjukan, dsb.), sering dalam bentuk
dokumen/email, meski ringkasannya bisa disebar juga lewat WA.

## Format (dokumen/email — bentuk baku)
```
MEMO INTERNAL

Kepada    : [Penerima, mis. "Seluruh Karyawan" / "Tim Operasional"]
Dari      : [Nama/Jabatan pengirim]
Tanggal   : [tanggal]
Perihal   : [judul memo singkat]

[Paragraf 1: latar belakang singkat — kenapa memo ini dibuat]

[Paragraf 2: isi kebijakan/keputusan secara jelas — gunakan poin bila lebih dari 1 hal]
1. [poin]
2. [poin]

[Paragraf 3: berlaku sejak kapan, dan apa yang perlu dilakukan penerima]

Demikian memo ini disampaikan untuk diketahui dan dilaksanakan sebagaimana mestinya.

[Nama pengirim]
[Jabatan]
```

## Ringkasan singkat untuk WA (setelah memo resmi dibuat)
```
📄 *Surat Edaran: [Judul]*
[1–2 kalimat inti]
Berlaku sejak: [tanggal]
Detail lengkap: [lihat dokumen terlampir / tanyakan ke [kontak]]
```

## Kapan pakai memo vs pengumuman biasa
- **Memo/surat edaran**: kebijakan yang perlu didokumentasikan resmi (ada nomor surat jika
  kantor punya sistem penomoran, perlu diarsipkan, mungkin dirujuk di kemudian hari).
- **Pengumuman biasa** (`pengumuman-internal.md`): info operasional sehari-hari yang tidak
  perlu status dokumen resmi (libur, jam kerja sementara, dsb.) — cukup diumumkan.
Jika pengguna tidak menyebutkan mana yang diinginkan dan isinya berupa kebijakan yang
cukup penting (perubahan SOP, aturan kerja baru), tanyakan sekali: "Ini perlu bentuk memo
resmi (dengan nomor surat) atau cukup pengumuman singkat di WA grup?"

## Nomor surat (jika kantor memakainya)
Jika pengguna menyebutkan format penomoran (mis. "001/MEMO-HR/IX/2026"), gunakan format
itu persis. Jika tidak disebutkan dan kantor kemungkinan belum punya sistem penomoran,
jangan mengarang nomor surat — tanyakan atau kosongkan baris tersebut.
