# Template Laporan Harian WFH/WFO

Laporan harian singkat, biasanya untuk absensi kerja/rekap harian yang diminta beberapa
kantor untuk karyawan WFH (Work From Home) atau juga dipakai WFO (Work From Office) yang
ingin tetap terdokumentasi. Prinsip: singkat, 3–5 baris, tidak perlu format 3P penuh.

## Format WFH
```
*Laporan Harian – [Nama]*
📅 [Tanggal] | 🏠 WFH
✅ Selesai hari ini: [1–2 kalimat]
🔜 Rencana besok: [1 kalimat]
⚠️ Kendala: [1 kalimat, atau "Tidak ada"]
```
Untuk WFH, kendala sering berupa akses/koneksi (mis. "sempat kehilangan koneksi internet
1 jam siang tadi") — sertakan bila disebutkan di bahan mentah, jangan diasumsikan.

## Format WFO
```
*Laporan Harian – [Nama]*
📅 [Tanggal] | 🏢 WFO
✅ Selesai hari ini: [1–2 kalimat]
🔜 Rencana besok: [1 kalimat]
```
Baris kendala opsional untuk WFO (biasanya sudah dikoordinasikan langsung tatap muka),
sertakan hanya jika ada hal yang perlu dicatat tertulis.

## Catatan
- Jika diminta rekap harian untuk BANYAK orang sekaligus (misal admin HR merekap seluruh
  tim), gabungkan satu blok per orang dengan format sama, dipisahkan baris kosong.
- Jangan mengisi "selesai hari ini" dengan tugas yang sebenarnya masih berjalan — kalau
  belum selesai, sebutkan progresnya (mis. "mengerjakan 60% laporan penjualan, lanjut besok").
