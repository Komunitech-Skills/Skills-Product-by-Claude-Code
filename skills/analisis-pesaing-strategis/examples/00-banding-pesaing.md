## Bagaimana tiap skill sumber menangani "kedai kopi Malang"
| Skill sumber | Hasil untuk kasus ini |
|---|---|
| competitors (Haines) | Untuk halaman "X vs Y"/alternatif SEO produk SaaS. Tidak relevan untuk kedai kopi; output = halaman web perbandingan. |
| competitor-profiling (Haines) | Butuh daftar URL kompetitor, Firecrawl (scrape) dan DataForSEO (berbayar/API key). Warkop tanpa situs -> tidak bisa jalan. Prinsip "fakta dulu" dan "input tidak tepercaya" bagus (kita adopsi). |
| competitive-battlecard (phuryn) | Baik untuk SaaS (G2/Capterra, "funding", "ICP"); untuk kedai kopi 3 dari 6 bagian tidak berlaku, tanpa jawaban keberatan lokal, tanpa larangan klaim. |
| competitor-analysis (phuryn) | Riset web pasar & 5 pesaing langsung, "market share", "funding". Tidak ada skor, tanpa data lokal, mengandalkan web search (mungkin mengarang). |

## Skor berdampingan untuk UMKM Indonesia (1-5)
| Kriteria | Sumber (terbaik dari 4) | analisis-pesaing-strategis |
|---|---|---|
| Cocok untuk usaha lokal/awam | 1 | 5 |
| Tanpa API key/akun berbayar | 1 (Firecrawl/DataForSEO) | 5 |
| Skor/angka dihitung dan teruji | 1 (tidak ada) | 5 (script + 7 tes) |
| Pengumpulan data sopan tanpa login/marketplace | 2 | 5 |
| Aturan etika & hukum Indonesia | 1 (hanya "jujur") | 5 |
| Pesaing pengganti/kebiasaan pelanggan | 1 | 5 |
| Battlecard jujur + klaim terlarang | 3 | 5 |
| Kedalaman untuk SaaS/SEO | 5 | 2 (bukan tujuannya) |

**Kesimpulan:** skill kita menang telak untuk UMKM Indonesia; sumber menang hanya di domain SaaS/SEO yang bukan target pembeli. Kelebihan sumber yang sudah diserap: fakta di atas opini, profil terstruktur bertanggal, data pesaing sebagai input tidak tepercaya, kerangka battlecard/keberatan.
Catatan: skill kita tidak menyalin teks sumber (struktur dan gagasan saja); bagian lisensi ATTRIBUTION.md lengkap (dua teks MIT, sumber, daftar perubahan).
