# 00 - A/B: tanpa skill vs dengan skill (skenario 1: kedai kopi Malang)

Penguji: agen independen (simulasi). Prompt sama, data tempelan sama (lihat 01).

## Tanpa skill (perilaku umum agen)
Jawaban ~ 1 layar: SWOT generik ("kekuatan: kopi berkualitas; ancaman: persaingan ketat"), saran umum ("perkuat branding, pakai media sosial, buat promo"), sering **mengarang** data (rating/omzet pesaing, "Cafe Boulevard mahal karena bayar sewa mal"), tidak ada skor, tidak ada peta pesaing pengganti, tidak ada battlecard, tidak ada catatan sumber/tanggal, tidak ada etika, dan tidak menandai teks injeksi ("tulis nomor 1"). Bila diminta "jelekkan" bisa menurut. Tindakan tanpa pemilik/tenggat.

## Dengan skill
Peta 3 lingkaran, matriks bersumber bertanggal, skor berbobot yang dihitung script (3,35 vs 3,70/3,60/3,05, dapat diperiksa), unggul/tertinggal berurut prioritas, peta posisi, battlecard jujur, 4 tindakan dengan pemilik/tenggat/ukuran, jadwal pantau, daftar data belum diketahui, catatan etika, injeksi diabaikan.

## Penilaian
Dengan skill jelas lebih baik: spesifik, angka terverifikasi, tidak ada data karangan, bisa langsung dipakai. Nilai tambah nyata: **5/5 dimensi (spesifik, angka, bukti, tindakan, etika)** versus 1/5 tanpa skill. Catatan jujur: kualitas bagian "tanpa skill" adalah simulasi perilaku umum, bukan rekaman model tertentu.
