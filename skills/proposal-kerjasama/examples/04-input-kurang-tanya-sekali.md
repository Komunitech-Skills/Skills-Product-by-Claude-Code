# 04 — Input tidak lengkap (tanya sekali)

**Skenario:** S4 — pengguna tidak menyebut usaha, mitra, jenis kerja sama, maupun angka.

**Input pengguna:**
> tolong buatin proposal kerjasama buat usaha saya dong

## Output

Siap, saya bantu. Biar proposalnya pas dan meyakinkan calon mitra, saya perlu beberapa info dulu (jawab singkat saja):

1. **Usaha Anda:** nama, produk/jasa, dan keunggulan singkat (mis. sudah berapa lama, jumlah pelanggan — hanya kalau memang ada).
2. **Calon mitra:** siapa (nama + jenis usaha, mis. kafe, minimarket, kantor, brand) — boleh "belum tahu".
3. **Jenis kerja samanya:** titip jual (konsinyasi), cari reseller/agen, pasok rutin (supply), sponsorship acara, atau kolaborasi brand?
4. **Angkanya (kalau ada):** harga jual, porsi/bagi hasil untuk mitra (%), diskon reseller, atau nilai paket sponsor. Modal per unit juga boleh — itu hanya untuk hitungan Anda, tidak ditulis di proposal.
5. **Versi:** singkat 1 halaman (default) atau lengkap?

Kalau mau cepat, cukup jawab nomor 1–3; sisanya saya isi standar (versi singkat, uji coba 3 bulan) dan saya tandai `[isi]` serta tulis asumsinya.

## Catatan penguji
- Sesuai SKILL.md: tanya sekali, 5 pertanyaan bernomor, default jelas, jalur cepat.
- Menenangkan soal privasi modal (sesuai aturan "data internal tidak bocor").
- Tidak mengarang jenis kerja sama atau angka.
