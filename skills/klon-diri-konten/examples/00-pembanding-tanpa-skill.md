# A/B - Skenario 01 (kedai kopi, 8 video/bulan) tanpa skill vs dengan skill (simulasi agent)

**Tanpa skill** (agent umum, tanpa folder skill): "Anda bisa pakai HeyGen atau Synthesia; harganya sekitar $24-$30/bulan. Rekam video bicara 2 menit dengan cahaya bagus, unggah, lalu ketik naskah." Tidak ada hitungan menit (8 x 45 detik), harga USD tanpa Rupiah, tidak ada gerbang persetujuan, tidak ada label AI, tidak ada peringatan verifikasi/keamanan, tidak ada kalender atau naskah latihan Indonesia, harga bisa usang/dikira.

**Dengan skill:** status persetujuan, 2 alat dengan harga bertanggal + Rupiah, hitungan script (7,5 menit; Rp478.500) yang diverifikasi Decimal, panduan rekam + naskah latihan, kalender + perintah ke skill naskah, kalimat label AI, 3 peringatan keamanan.

**Hasil:** dengan skill jelas lebih baik (siap pakai, angka dihitung, aman). Layak jadi "sebelum/sesudah" README.
