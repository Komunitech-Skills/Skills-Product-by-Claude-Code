# Contoh 2 - Klon suara admin toko (harus izin tertulis)

**Input:** "Suara admin saya bagus, saya klon saja buat narasi video, dia lagi cuti."
**Respons skill:** berhenti di gerbang persetujuan. Klon orang lain hanya dengan persetujuan tertulis dan sadar dari orangnya. Langkah: (1) minta admin menyetujui secara langsung; (2) isi Bagian B `templates/formulir-persetujuan-klon.md` (tujuan, platform, jangka waktu, imbalan, hak mencabut); (3) admin merekam sampel sendiri; (4) label AI. Bila admin belum setuju: pakai suara bawaan alat atau rekam suara Anda sendiri. Skill tidak membuat klon dari rekaman tanpa sepengetahuan admin.
