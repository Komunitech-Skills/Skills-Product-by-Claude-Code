# Skenario 3 — Normal (malas/singkat)

## Input pengguna
```
bikinin dong ICP buat produk kemasan makanan ramah lingkungan gue, sekalian
sumber cari calon pelanggannya
```

## Output

```
Oke, saya bantu ya. Karena belum ada detail lain, saya pakai asumsi wajar dulu
(saya sebutkan di bawah) — kalau ada yang meleset, tinggal koreksi.

## Profil Pelanggan Ideal (ICP)
Bisnis F&B skala kecil-menengah (UMKM katering, resto, kafe, produsen makanan
ringan/frozen food) yang butuh kemasan untuk produk take-away/delivery dan mulai
peduli citra ramah lingkungan (mis. untuk pasar anak muda/urban). Pengambil
keputusan: pemilik usaha atau bagian purchasing/operasional. Kemampuan bayar:
sedang — sanggup beli dalam jumlah rutin bulanan (bukan sekali beli satuan kecil).

Ciri-ciri:
- Sudah jualan aktif (bukan baru rencana usaha)
- Order kemasan rutin, bukan sesekali
- Segmen pasar yang peduli isu lingkungan (brand yang menonjolkan "sustainable",
  "eco-friendly", dst di media sosialnya)

## Sumber Pencarian yang Disarankan
- Instagram/media sosial: cari bisnis F&B lokal yang mempromosikan diri sebagai
  "eco-friendly"/"ramah lingkungan" — lihat kontak bisnis di bio
- Google Maps: cari kategori resto/katering/frozen food di area target Anda
- Marketplace B2B (Indotrading, Ralali) untuk mencari calon reseller/distributor
  kemasan sekaligus melihat siapa saja yang mencari kemasan serupa
- Komunitas UMKM F&B (grup WhatsApp/Telegram, event pameran kuliner)

|---|---|---|---|

## Asumsi
- Target pasar: F&B skala UMKM-menengah, tanpa area spesifik (sebutkan kota/area
  Anda kalau mau saya persempit)
- Skala usaha & kapasitas produksi kemasan Anda belum diketahui — kalau produksi
  Anda masih kecil, sebaiknya jangan dulu incar resto besar/rantai nasional
- Saluran outreach belum ditentukan → saya siapkan opsi WA dulu (paling umum
  untuk UMKM), beri tahu kalau mau versi email/LinkedIn juga
```

## Catatan penguji
- Meski permintaan sangat singkat/malas, skill tetap menjalankan Langkah 1-3
  SKILL.md dengan baik: ICP tersusun, sumber pencarian relevan dan spesifik
  (bukan generik "cari di internet"), asumsi disebutkan jelas sesuai aturan
  Input ("Jika pengguna ingin cepat, pakai asumsi masuk akal dan sebutkan").
- Tidak ada daftar calon pelanggan fiktif — kerangka kosong, sesuai Langkah 3.
- Tidak ada cacat berat/sedang. Cacat ringan: karena permintaan tidak menyebut
  lokasi sama sekali, output bisa terasa agak umum (tidak ada kota target);
  ini sudah ditangani dengan benar lewat asumsi & pertanyaan balik, jadi
  dampaknya kecil.
