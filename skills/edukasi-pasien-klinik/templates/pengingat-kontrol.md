## Pengingat kontrol
```
Halo [Nama Pasien/Orang Tua — samarkan bila untuk contoh/dokumentasi],

Ini pengingat jadwal kontrol Anda di [Nama Klinik]:
📅 [tanggal], pukul [jam]
📍 [lokasi/poli]

jadwal.

[Nama Klinik]
```

## Pengingat imunisasi/vaksin
```
Halo [Nama Orang Tua/Pasien — samarkan bila untuk contoh/dokumentasi],

Jadwal imunisasi [nama anak — samarkan bila untuk contoh] sudah dekat:
💉 [jenis imunisasi, dari data klinik]
📅 [tanggal], pukul [jam]
📍 [lokasi]

Yang perlu dibawa: buku KIA / kartu vaksinasi, KTP orang tua.

Ada pertanyaan atau perlu jadwal ulang? Hubungi kami di [kontak klinik].

[Nama Klinik]
```

**Catatan privasi:** saat membuat CONTOH pesan untuk dokumentasi/uji, ganti nama asli dengan
nama contoh (mis. "Ibu A", "Ananda B") — jangan pernah menyalin data pasien sungguhan ke luar
sistem klinik.
