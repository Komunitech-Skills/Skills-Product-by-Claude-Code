# Template: Leaflet/Pesan Pasca-Tindakan

Isi bagian `[dari dokter]` dengan poin yang diberikan dokter/tenaga kesehatan. Skill hanya
merapikan bahasa dan format — tidak menambah instruksi medis baru.

```
🏥 [Nama Klinik]
Perawatan Setelah [Nama Tindakan] — [Tanggal]

Terima kasih sudah datang hari ini. Berikut panduan perawatan di rumah:

✅ Boleh / dianjurkan
- [dari dokter, poin 1]
- [dari dokter, poin 2]

🚫 Hindari dulu
- [dari dokter, poin 1]
- [dari dokter, poin 2]

💊 Obat (jika ada resep)
- [Nama obat] — [dosis] — [jadwal minum] — selama [durasi]
  (disalin persis dari resep/instruksi dokter)

⚠️ Segera hubungi klinik / ke IGD terdekat bila:
- [dari dokter, tanda yang perlu diwaspadai — isi hanya jika dokter menuliskannya]

📅 Kontrol berikutnya
- [tanggal/rentang dari klinik], di [Nama Klinik]

📞 Ada pertanyaan? Hubungi kami di [nomor/kontak klinik].

Catatan: pesan ini bukan pengganti konsultasi. Kalau kondisi memburuk atau terasa darurat,
segera ke IGD terdekat atau hubungi 119 — jangan menunggu balasan chat ini.
```
