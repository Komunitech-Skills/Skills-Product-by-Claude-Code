# Panduan Gaya Tulisan Alami — Untuk Dipakai Skill Lain

Skill konten lain di library ini (`konten-mingguan`, `kalender-konten-30hari`, `copy-landing-page`,
`pesan-prospek-wa`, `balas-chat-cs`, dan skill konten berikutnya) boleh merujuk file ini di langkah
terakhir penulisannya, misalnya: *"Sebelum mengirim hasil, cocokkan dengan
`tulisan-tanpa-kesan-ai/references/panduan-gaya.md` — kalau skill itu terpasang, panggil mode periksa
sekali sebelum output final."*

## Prinsip inti
1. **Suara pengguna di atas segalanya.** Jangan menyeragamkan gaya semua output supaya "rapi" — kalau
   pengguna sudah kasih contoh gaya bicara sendiri (santai, blak-blakan, formal), ikuti itu, bukan
   gaya default skill.
2. **Aktif, bukan pasif.** "Tim kami kirim pesanan hari ini" lebih hidup dari "pesanan dikirimkan oleh
   tim kami hari ini". Subjek manusia melakukan aksi, bukan benda mati.
3. **Konkret, bukan abstrak.** Angka, nama, mekanisme, contoh nyata mengalahkan kata sifat umum.
   "Cepat" → "selesai dalam 1 jam". "Berkualitas" → "pakai bahan X, bukan Y".
4. **Kalimat pendek, ritme wajar.** Bahasa lisan sehari-hari boleh pakai kalimat pendek dan variatif;
   jangan paksa semua kalimat sama panjang/sama bentuk (itu sendiri jadi pola robotik — lihat
   `pola-ai-indonesia.md` #6).
5. **Setiap kalimat harus "milik" tulisan ini.** Uji portabilitas: kalau kalimat itu bisa ditempel ke
   produk/topik lain tanpa diubah dan tetap "masuk akal", kalimat itu kemungkinan besar filler —
   hapus atau buat spesifik.
6. **Jangan mengarang untuk terdengar meyakinkan.** Klaim superlatif, statistik, atau "penelitian
   menunjukkan" tanpa sumber nyata bukan cuma pola AI — juga berisiko hukum periklanan
   (lihat `copy-landing-page/references/dasar-hukum-klaim.md` untuk aturan klaim produk Indonesia).
7. **Format ikut isi, bukan dekorasi.** Bullet, bold, emoji, heading dipakai kalau memang membantu
   pembaca, bukan ditabur otomatis di semua output.

## Cara skill lain memakai ini
- **Ringan (disarankan default):** setelah menulis draf, cek sendiri terhadap daftar pola di
  `pola-ai-indonesia.md` sebelum mengirim ke pengguna — tidak perlu menjalankan skill terpisah.
- **Lewat skill ini secara eksplisit:** kalau pengguna minta "cek dulu bau AI-nya" atau skill ingin
  langkah pemeriksaan tambahan, arahkan ke mode periksa/perbaiki `tulisan-tanpa-kesan-ai` seperti
  dijelaskan di `SKILL.md` skill ini.
- Jangan duplikasi daftar pola panjang ini ke tiap skill konten — cukup rujuk file ini supaya kalau
  daftar pola diperbarui, semua skill ikut terbarui.
