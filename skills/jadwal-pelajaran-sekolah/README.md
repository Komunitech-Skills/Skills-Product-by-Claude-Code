# Jadwal Pelajaran Sekolah — siap tanpa bentrok

**Tagline:** Tempel daftar guru & mapel — dapat grid mingguan siap cetak, tanpa tabrakan jam.

## Manfaat
- Menghemat penyusunan jadwal manual berhari-hari untuk SMP/SMA/bimbel kecil–menengah.
- Guru tidak double di jam yang sama; kelas tidak dapat dua mapel sekaligus.
- Angka JP terjadwal dihitung otomatis (bukan tebak-tebakan).
- CSV siap salin ke Sheets atau WA ke guru.

## Cocok untuk
- Kepala sekolah, admin TU, koordinator kurikulum, pengelola bimbel/kursus.

## Sebelum / sesudah
- **Sebelum:** model AI memberi saran jam acak tanpa cek bentrok antar guru/kelas.
- **Sesudah:** tabel terstruktur + validasi slot; akan diisi lengkap setelah uji independen.

## Instalasi
Salin folder `jadwal-pelajaran-sekolah` ke lokasi skill platform Anda — lihat `docs/instalasi.md` di paket.

## FAQ
1. **Perlu FET?** Tidak wajib; FET opsional untuk sekolah besar (lihat `references/panduan-fet.md`).
2. **SD/SMK?** Ya — sesuaikan jumlah jam/hari di chat.
3. **Bisa kirim otomatis ke orang tua?** Tidak; skill hanya menyiapkan jadwal, pengiriman manual staf.
