# Contoh 3: input tidak lengkap (uji ulang v1.0.1, 2026-10-12)

## Masukan pengguna
"bikinin jadwal pelajaran"

## Keluaran dengan skill
Meminta satu hal wajib (daftar guru, kelas, mapel, JP per minggu) dengan contoh format siap tempel (`guru;kelas;mapel;jp`), menyebut default (Senin-Jumat, 6 slot, 40 menit, istirahat setelah jam ke-2 dan ke-4) dan dua pertanyaan opsional (guru paruh waktu, ruang khusus). Tanpa nama berkas atau jargon.

## Catatan
Skor SESUDAH 8,0 vs SEBELUM 6,0 (tanpa skill: 5 pertanyaan, sebagian salah tafsir sebagai jadwal belajar anak/pribadi). Belum memberi jadwal contoh kecil ("kerjakan dulu").
