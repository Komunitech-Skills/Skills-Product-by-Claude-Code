# Contoh 3: input tidak lengkap (uji OpenClaw 2026-10-12)

## Masukan pengguna
"bikinin jadwal pelajaran"

## Keluaran dengan skill
Meminta daftar guru-mapel-kelas-JP dengan contoh format ("boleh tabel biasa, gak perlu rapi"), menyebut default (Senin-Jumat, 6 slot, istirahat setelah jam ke-2 dan ke-4) bila hari/jam tidak disebut, dan menanyakan jenjang (SD/SMP/SMA/bimbel). Tiga poin, bahasa awam.

## Catatan
