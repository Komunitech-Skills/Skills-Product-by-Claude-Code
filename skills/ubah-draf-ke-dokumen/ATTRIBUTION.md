# Atribusi — ubah-draf-ke-dokumen

Karya orisinal Komunitech (proprietary; tunduk `LISENSI.txt` paket).

- Ide fungsi konversi dokumen terinspirasi riset proyek open-source (Pandoc, jgm/pandoc, GPL-2.0+) — **tidak** menyalin kode atau template Pandoc; implementasi `.docx` memakai Python standar (zipfile + OOXML) buatan Komunitech.
- Contoh nama, alamat, dan angka di dokumentasi **fiktif**.
- Template kop/notulen ditulis khusus untuk pasar Indonesia.
