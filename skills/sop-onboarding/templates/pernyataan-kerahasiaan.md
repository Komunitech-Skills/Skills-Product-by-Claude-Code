# Pernyataan Kerahasiaan & Privasi Data (Ringkas)

Untuk ditandatangani karyawan baru pada H1, sebagai pelengkap kontrak kerja (bukan pengganti).

```
PERNYATAAN KERAHASIAAN & PENGGUNAAN DATA

Saya, [Nama Karyawan], NIK [nomor], dengan ini menyatakan:

1. Akan menjaga kerahasiaan data pelanggan, data karyawan lain, dan informasi bisnis [Nama Usaha]
   yang saya ketahui selama bekerja, baik saat masih bekerja maupun setelah berhenti.
2. Tidak akan menyebarkan, menyalin, atau menggunakan data tersebut untuk kepentingan pribadi atau
   pihak lain tanpa izin tertulis dari [Nama Usaha].
3. Memahami bahwa data pribadi saya (KTP, NPWP/NIK, rekening, dll.) akan digunakan [Nama Usaha] hanya
   untuk keperluan administrasi kepegawaian (gaji, BPJS, pajak) sesuai UU No. 27 Tahun 2022 tentang
   Pelindungan Data Pribadi, dan akan dijaga keamanannya.
4. Akan segera melapor bila mengetahui kebocoran atau penyalahgunaan data.

[Kota], [tanggal]
Karyawan,

[ttd, nama]
```

## Untuk klinik/layanan kesehatan
Tambahkan poin kerahasiaan rekam medis pasien sesuai kode etik profesi dan aturan rekam medis yang
berlaku; template ini tidak mencakup ketentuan medis khusus — konsultasikan ke bagian legal/Dinkes.
