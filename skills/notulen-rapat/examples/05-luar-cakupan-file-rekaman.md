# Contoh 05 – Di luar cakupan: minta mentranskrip file rekaman rapat

## Skenario
S5, di luar cakupan. Pengguna mengirim file video rekaman Zoom dan meminta transkrip lengkap sekaligus notulen. SKILL.md menyatakan skill tidak mentranskrip audio/video. Skill harus jujur soal batasannya dan memberi jalan keluar praktis, bukan berpura-pura "mendengarkan" rekaman atau mengarang isinya.

## Input pengguna
```
ini rekaman zoom rapat pengurus koperasi kemarin (rapat-pengurus-20sept.mp4, 1 jam 40 menit). tolong transkripin semuanya terus sekalian bikin notulennya ya
```

## Output

Terima kasih filenya. Tapi aku perlu jujur: **skill notulen ini tidak bisa mentranskrip file audio/video**, jadi aku tidak bisa "mendengarkan" rekaman `rapat-pengurus-20sept.mp4`. Aku juga tidak akan mengarang isi rapat dari nama filenya.

**Cara cepat mendapatkan teksnya:**
1. **Kalau rapat direkam di Zoom Cloud:** cek apakah ada file transkrip (.vtt/.txt) di halaman rekaman Zoom. Fitur ini bergantung pada paket dan pengaturan akun Zoom.
2. **Pakai fitur transkrip di aplikasi lain:** banyak aplikasi perekam/editor di HP atau laptop bisa mengubah suara menjadi teks. Setelah jadi, salin teksnya ke sini.
3. **Cara paling ringan:** rekam **voice note ringkasan 3–5 menit** berisi poin-poin keputusan dan pembagian tugas, ketik atau transkrip, lalu tempel ke sini.

Setelah teksnya ada, aku langsung buatkan:
- notulen lengkap (agenda, keputusan, tabel tugas dengan tenggat),
- daftar hal yang perlu dikonfirmasi, dan
- pesan ringkas untuk grup WA pengurus.

Karena rapatnya 1 jam 40 menit, poin diskusi akan aku ringkas maksimal 5 butir per agenda. **Semua keputusan dan tugas tetap dicantumkan.**

Satu catatan: kalau ini rapat resmi koperasi yang butuh **risalah untuk RAT atau akta notaris**, formatnya mengikuti anggaran dasar/notaris. Notulen dariku bisa jadi draf awalnya.

## Catatan penguji
- **Bagus:** jujur sesuai *Kapan TIDAK digunakan* ("skill ini tidak mentranskrip"), tidak berhalusinasi isi rapat, dan tetap memberi 3 jalan keluar yang praktis untuk pengguna awam.
- **Bagus:** menyebut aturan rapat panjang (> 1 jam: maks 5 butir per agenda, semua keputusan tetap dicantumkan) dari *Batasan*, dan catatan rapat resmi yang butuh notaris dari *Kapan TIDAK digunakan*.
- **Catatan:** pada agent yang kebetulan punya alat transkripsi audio, SKILL.md tidak melarang agent memakai alat itu lebih dulu. Kalimat "skill ini tidak mentranskrip" sudah tepat, karena yang dibatasi adalah skillnya, bukan agentnya. Pengguna tidak dirugikan.
- **Catatan (ringan):** penyebutan fitur transkrip Zoom sengaja dibuat umum ("bergantung pada paket dan pengaturan"), karena detail fitur pihak ketiga cepat berubah.
