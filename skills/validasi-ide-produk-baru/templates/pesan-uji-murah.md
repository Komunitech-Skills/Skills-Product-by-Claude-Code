# Template Pesan Uji Murah

Isi bagian dalam kurung siku `[...]`, hapus kurungnya setelah diisi. Semua template sengaja singkat dan langsung ke inti (tidak berbelit) supaya calon pembeli mudah merespons cepat.

## 1. Broadcast/status WA — pre-order
```
Halo [nama panggilan]! 👋

Aku lagi coba mulai jual [nama produk/jasa] — [deskripsi singkat 1 kalimat, fokus manfaat].

Harga: Rp[harga] / [satuan]
[Detail singkat: rasa/varian/opsi, kalau ada]

Kalau [jumlah] minat, aku mulai [bikin/produksi/buka] minggu ini.
Mau pesan? Balas "MAU + jumlah" ke chat ini sebelum [tanggal, maks 7 hari dari sekarang] ya. 🙏

[Nama kamu/usaha]
```

## 2. Caption story WA (foto/video produk)
```
Lagi coba-coba jual [nama produk] nih 👀
[1 kalimat manfaat/kenapa beda]
Rp[harga] — chat aku kalau tertarik, khusus minggu ini!
```

## 3. Caption polling story Instagram
```
Lagi mikir mau mulai jualan [nama produk] 🤔
[1 kalimat manfaat]
Harga rencana: Rp[harga]

Kalau ada, kamu bakal beli? [stiker polling: Ya, mau! / Nanti dulu]

(DM aku kalau mau pesan duluan pas udah jadi 😊)
```

## 4. Deskripsi listing PO (pre-order) marketplace
```
[NAMA PRODUK] — PO (Pre-Order), estimasi kirim [X] hari setelah order

[2-3 kalimat: apa produknya, manfaat/keunggulan, untuk siapa]

✅ [keunggulan 1]
✅ [keunggulan 2]
✅ [keunggulan 3]

Catatan: produk ini sistem PO (dibuat setelah order masuk), jadi butuh waktu [X] hari sebelum dikirim. Kalau butuh cepat, chat dulu ya sebelum order.

Kuota terbatas: hanya [jumlah] pembeli pertama untuk batch percobaan ini.
```

## 5. Pitch titip di warung/reseller
```
Halo Bu/Pak [nama pemilik warung],

Saya [nama] mau nitip coba [nama produk] di warung/toko [nama tempat], sistem konsinyasi (bayar setelah laku, gak ada risiko rugi buat warung).

- Harga titip: Rp[harga beli warung]
- Harga jual disarankan: Rp[harga jual ke pembeli]
- Jumlah titip percobaan: [jumlah] pcs
- Saya cek & ambil sisa/uang hasil jualan di [tanggal, ±7 hari]

Boleh nitip minggu ini, Bu/Pak? 🙏
```

## 6. Pesan tanya alasan tidak beli (opsional, tapi berharga)
Kirim singkat ke yang jawab "nanti dulu"/"enggak dulu":
```
Oke, gak apa-apa! Boleh tau kenapa belum tertarik? (harga / belum butuh / mau lihat dulu / lainnya) — biar aku bisa perbaiki 🙏
```
