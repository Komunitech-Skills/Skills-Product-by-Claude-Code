## 0. Metode & batasan

- **Lingkup:** proyek/konten top berlisensi BSD-2/BSD-3, ISC, CC0/Unlicense/MIT-0, dan CC-BY 4.0 (bukan MIT murni, bukan Apache; CC-BY-SA dan CC-BY-NC hanya dicatat & ditandai). Tambahan pemilik (pesan koordinator, sesi ini): proyek top bersetup berat (MCP server, Docker, Node, API key) **tetap dicatat** dengan label **INTERNAL Komunitech** (riset, produksi skill, CS, operasional) dan tidak ditolak karena setup berat. Karena itu tabel punya kolom **Untuk: audiens / internal** dan ada bagian **Top 3 internal** terpisah dari Top 5 audiens.
- **Alat:** WebSearch + WebFetch (halaman GitHub/situs resmi), pencarian repositori GitHub lewat alat MCP `search_repositories` (memberi bintang/fork/lisensi terdeteksi/tanggal; `api.github.com` langsung tetap 403), dan **LICENSE dibaca langsung dari `raw.githubusercontent.com`** (teks lisensi, bukan tebakan). Tidak ada clone, tidak ada kode dijalankan.
- **Dedup:** semua repo di `research/sources/*.md` (daftar `grep github.com`) dan 150+ nama skill di `catalog.csv` dicek; semua kandidat di bawah **belum pernah dinilai** (Dolibarr, Odoo, Saleor, hledger, Grist, Datasette, Chatwoot, dst. sudah dinilai sebelumnya dan tidak diulang).
- **Batasan:** (1) ringkasan WebFetch dibuat model kecil, jadi angka halaman non-GitHub (OpenStax, FDIC, Google) dibaca sekali dan perlu cek ulang oleh pembuat skill; (2) tanggal "update" repo GitHub diambil dari `updated_at` API pencarian (mendekati tanggal aktivitas terakhir, bukan selalu commit); (3) ClawHub/skills.sh tidak menampilkan lisensi per skill selain kebijakan platform (semua skill ClawHub = MIT-0 menurut `docs/skill-format.md` repo openclaw/clawhub).
- **Temuan penting metode:** pencarian GitHub `license:bsd-3-clause|cc0-1.0|unlicense|isc` + topik skill hanya menghasilkan repo skill kecil (≤ 176★, mayoritas developer). Sumber kuat untuk audiens awam justru **proyek perangkat lunak BSD (algoritma/ide)**, **konten CC-BY 4.0 dari organisasi resmi**, dan **konten domain publik pemerintah AS** (bukan CC0 formal, ditandai terpisah).

**Catatan lisensi domain publik pemerintah AS:** FDIC, FDA, FEMA, FTC adalah karya pemerintah federal AS (17 U.S.C. §105, tidak ada hak cipta di AS) — bukan CC0 formal. Dimasukkan karena fungsinya sama dengan CC0 untuk kita, tapi **PERLU REVIEW pemilik** (materi pihak ketiga di dalamnya bisa tetap berhak cipta; foto/grafik tidak disalin).

## 2. Top 5 rekomendasi untuk AUDIENS

1. **numpy-financial → `simulasi-cicilan-pinjaman` + `kelayakan-investasi-usaha`** (BSD-3, NumPy org, 411★, aktif). Rumus keuangan standar dihitung dengan script (bukan dikira), dibungkus untuk kasus nyata UMKM: bunga flat vs efektif/anuitas (motor, HP, pinjol, KUR), jadwal angsuran, total bunga & EIR, payback/NPV/IRR beli mesin atau buka cabang. Sangat sesuai prinsip "angka dihitung, tidak dikira" dan melengkapi `analisis-rasio-keuangan-usaha`/`pengajuan-kur`; tidak butuh API/instalasi.
2. **FDA Food Code → `checklist-keamanan-pangan-usaha`** (domain publik pemerintah AS, bukan CC0 formal). Pasar UMKM kuliner (kafe/warung/katering rumahan) besar & harian; kerangka suhu, kontaminasi silang, kebersihan, alergen mudah jadi checklist+log. **Syarat:** rujukan lokal (higiene sanitasi, PIRT/BPOM, halal) harus diverifikasi dan skill diberi PERLU REVIEW; cocok `paket-kafe-warung`.
3. **OpenRefine (BSD-3, 12k★) + Data Carpentry (CC BY 4.0) → `rapikan-data-berantakan`** — 5 sinyal penuh. Masalah nyata awam: nama pelanggan/produk ejaan beda, nomor HP campur 08/62/+62, tanggal ambigu, duplikat. Skill memakai ide *clustering* (fingerprint, n-gram, Levenshtein) dalam script stdlib + panduan mencatat rapi dengan atribusi CC-BY.
4. **Google Technical Writing (CC BY 4.0) → `sunting-tulisan-jelas`** — materi resmi Google, masih diperbarui (Agu 2025), lisensi tertulis di halaman. Dipakai tiap hari (email, proposal, SOP, laporan); menang telak vs "tolong rapikan" biasa bila ada ukuran (panjang kalimat, pasif, daftar) dan versi sebelum/sesudah. Beda jelas dari `tulisan-tanpa-kesan-ai`.
5. **FDIC Money Smart for Small Business (domain publik, "free of copyrights") → `cek-risiko-dan-asuransi-usaha`** — materi resmi lengkap dan eksplisit boleh diedit; modul Risiko/Asuransi/Suksesi belum tertutup skill kita (`laporan-insiden-usaha` hanya reaktif). Tambahan: managers-playbook (#6, CC BY 4.0, 5,5k★) → `satu-lawan-satu-dan-umpan-balik` adalah cadangan #6 yang kuat (HR belum punya skill percakapan atasan–tim).

**Catatan jujur:** prompts.chat (#9, 172k★, CC0) sangat populer dan legal paling bersih, tetapi prompt-nya pendek & mutu tidak seragam; nilainya ide judul peran, hampir seluruh isi skill tetap karya Komunitech. creative-director-skill (#8) wajib baris atribusi pada turunan.
