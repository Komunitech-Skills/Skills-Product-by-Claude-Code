## 2. Cara verifikasi (kejujuran metodologi)

Lingkungan kerja sesi ini **tidak bisa menjalankan Docker** (daemon Docker diblokir kebijakan sandbox — bukan kebijakan jaringan) dan halaman `github.com/.../releases` serta `api.github.com` sempat menjawab 403 lewat proxy sesi (ternyata perlu `add_repo` untuk diizinkan, bukan blokir organisasi — dicek lewat `__agentproxy/status`, `recentRelayFailures` kosong). Setelah `add_repo` (akses **baca saja**, tanpa push), kedua repo di-*clone* **dangkal (`--depth 1`)** langsung dari GitHub resmi:
- `gristlabs/grist-core` @ commit `e6632a7c...` (cabang `main`, 25 Sep 2026)
- `gristlabs/grist-desktop` @ commit `ff645e51...` (cabang `main`)

Dari situ diverifikasi **langsung membaca kode sumber asli** (bukan dari ingatan/pelatihan):
- `sandbox/grist/schema.py` — skema tabel metadata Grist (`_grist_Tables`, `_grist_Tables_column`, dst.), dipakai untuk merancang `tests/fixtures/*.grist` yang **realistis**.
- `app/server/lib/DocStorage.ts` baris ±1113: tabel data pengguna dibuat lewat `CREATE TABLE <tableId> (id INTEGER PRIMARY KEY, ...)` — mengonfirmasi bahwa **setiap tabel Grist adalah tabel SQLite biasa bernama persis `tableId`**, dengan kolom `id` sebagai primary key integer.
- `app/server/lib/DocApi.ts` — daftar route REST API resmi: `GET/POST/PATCH/PUT /api/docs/:docId/tables`, `.../tables/:tableId/records`, `.../tables/:tableId/columns`, `POST /api/docs/:docId/sql` (baca SQL read-only), dll.
- Header otorisasi API: `Authorization: Bearer <kunci>` (dikonfirmasi dari komentar & kode di file otorisasi API).
- Port default Docker: **8484** (`EXPOSE 8484`, `docker run -p 8484:8484 -it gristlabs/grist` — dari `README.md` resmi `grist-core`).
- `LICENSE.txt` dan `NOTICE.txt` dibaca langsung (isi di atas).

**Repo tidak disalin ke produk.** Clone hanya dipakai untuk riset di sesi ini (folder di luar `Skills/`, tidak pernah ditambahkan ke git repo Komunitech). Tidak ada baris kode Grist yang disalin ke `skills/grist-usaha/scripts/grist.py`; script kami memanggil REST API lewat HTTP dan membaca file `.grist` lewat `sqlite3` standar Python — komunikasi antar-program, bukan turunan kode.

**Yang TIDAK bisa diuji langsung di sesi ini** (jujur, lihat juga `docs/panduan-grist.md` §0 dan `skills/grist-usaha/README.md`):
- Menjalankan container `gristlabs/grist` sungguhan (Docker daemon diblokir kebijakan sandbox sesi ini, bukan mustahil di komputer pembeli).
- Mengklik aplikasi desktop resmi (lingkungan ini tidak punya layar/GUI).
- Karena itu, endpoint REST API & format file `.grist` diuji dengan **file `.grist` (SQLite) tiruan** yang skemanya disusun sama persis dengan `sandbox/grist/schema.py` resmi (lihat `skills/grist-usaha/tests/fixtures/`), bukan hasil ekspor Grist sungguhan. Endpoint REST hanya diuji secara statis (dibaca dari kode sumber), **belum** dipanggil ke server hidup. Ini dicatat apa adanya di `platform_teruji` (`claude-code (simulasi agent)`) dan tidak diklaim sebagai "sudah diuji end-to-end" ke pembeli.

## 3. Keputusan kurasi

**Jalur:** kurasi software (jalur A, sesuai `research/software-pengganti-saas-2026-09-23.md`) — **BUKAN** distribusi ulang. Komunitech **tidak pernah menyertakan** file installer/image Grist dalam paket ZIP. Pembeli mengunduh sendiri dari:
- Docker: `docker pull gristlabs/grist` (Docker Hub resmi) — untuk `grist-core`.
- Desktop: halaman **Releases** resmi https://github.com/gristlabs/grist-desktop/releases (installer `.exe`/`.dmg`/`.AppImage`/`.deb`).

**Alasan boleh dikurasi (sesuai aturan lisensi CLAUDE.md §Tahap 2):**
- Apache-2.0 = boleh dimodifikasi & dijual, syaratnya sertakan teks lisensi + atribusi + `NOTICE` asli + keterangan file yang diubah. Karena kita **tidak mendistribusikan/memodifikasi Grist sendiri** (hanya memanggil API-nya dari luar), kewajiban itu **tidak berlaku untuk kode Grist** — tapi tetap kami cantumkan di `skills/grist-usaha/ATTRIBUTION.md` sebagai kejujuran & etika, plus salinan `NOTICE.txt` asli untuk referensi pembeli.
- Bukti pemakaian nyata: bintang GitHub tinggi (`grist-core` termasuk proyek populer di kategorinya — lihat riset 2026-09-23, >11.000★), pembuat kredibel (vendor resmi Grist Labs Inc., juga menjual versi cloud/enterprise), rilis bertahap dengan commit teratur (bukan AI slop), dipakai luas (template resmi di templates.getgrist.com, dokumentasi lengkap support.getgrist.com).

**Nilai tambah Komunitech (wajib, skill publik gratis tidak boleh dijual apa adanya):**
1. Panduan instalasi bahasa Indonesia untuk awam (Windows/Mac/Linux, Docker **hanya localhost**, tanpa skrip unduh-dan-eksekusi-langsung) — `docs/panduan-grist.md`.
2. Template tabel siap pakai untuk UMKM Indonesia: daftar pelanggan, pesanan, stok sederhana, jadwal konten — `skills/grist-usaha/references/pola-tabel-umkm.md`.
3. Kumpulan rumus Grist (Python sandbox Grist) yang sudah teruji nalar untuk kebutuhan umum UMKM (total setelah diskon, status stok, umur piutang, dsb.) — `skills/grist-usaha/references/rumus-umum.md`.
4. Script Python standar (`scripts/grist.py`) untuk: rancang struktur tabel dari kalimat bebas, bersihkan & impor CSV, baca file `.grist` (SQLite) read-only untuk laporan tanpa perlu Grist menyala, dan panggil REST API lokal (kunci API disimpan di file lokal, tidak pernah dicetak).
5. Pemisahan tegas dengan `buku-stok`/`crm-wa` (aplikasi kecil buatan Komunitech, skema tetap) dan `analisis-excel` (analisis file apa adanya) — dijelaskan di `SKILL.md` §"Pilih yang mana".
