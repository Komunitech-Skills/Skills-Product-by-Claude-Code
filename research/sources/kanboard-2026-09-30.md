## 3. Metodologi verifikasi (jujur)
- **Docker:** CLI `docker` ada di kontainer sesi, tetapi daemon tidak berjalan ("Cannot connect to the Docker daemon") → image resmi **tidak** diuji. Daemon tidak dinyalakan paksa oleh agent.
- **Kanboard asli dijalankan:** repo di-clone (`git clone --depth 1 --branch v1.2.54`, akses baca publik; unduhan arsip rilis diblokir proxy sesi) ke scratchpad, lalu dijalankan dengan `php -S 127.0.0.1:8080` (PHP 8.4.19, pdo_sqlite) dan `APP_VERSION=v1.2.54` (variabel yang juga dipakai image Docker resmi, lihat `docker/etc/php84/php-fpm.d/env.conf`; tanpa itu clone git melaporkan `main.unknown_revision`). **Catatan:** PHP built-in server bukan cara resmi (docs tidak menyebutnya); dipakai hanya untuk uji, dan di panduan pembeli ditandai "coba cepat saja".
- Kode sumber dibaca **untuk memastikan antarmuka** (tidak disalin): `app/Api/Procedure/*.php`, `app/Api/Authorization/ProcedureAuthorization.php`, `app/Core/DateParser.php`, `app/Validator/TaskValidator.php`, `app/Template/user_api_access/show.php`, `app/Locale/id_ID/translations.php` (nama menu Indonesia).

## 4. Temuan API (diamati langsung di v1.2.54 asli)
| Hal | Perilaku nyata |
|---|---|
| Endpoint & auth | `POST /jsonrpc.php`, JSON-RPC 2.0, HTTP Basic. Token aplikasi = user `jsonrpc` + token di Pengaturan → API. Token pribadi = username + token (Profil saya → API → "Generate token baru"). Sandi akun juga diterima (tidak disarankan; wajib token bila 2FA) |
| Kredensial salah | HTTP 401 + `{"error":{"code":401,"message":"Unauthorized"}}` |
| Tidak berhak **atau** id tidak ada | HTTP 403 + `{"error":{"code":403,"message":"Forbidden"},"id":null}` (tidak ada 404 terpisah — `getTask` id 999 → 403) |
| Metode tak dikenal | `-32601 Method not found`; parameter kurang → `-32602 Invalid params` |
| Mode user vs aplikasi | `getMe`/`getMyProjects` hanya untuk user (token aplikasi → 403). `getAllProjects` → 403 untuk user biasa; untuk app-admin lewat user API ia mengembalikan semua proyek, tetapi `getColumns`/`getAllTasks` proyek yang admin bukan anggotanya tetap 403 (dan `getMyProjects` admin = [] bila bukan anggota). Skill memakai `getMyProjects` untuk token pribadi, `getAllProjects` untuk `jsonrpc` |
| Buat proyek | `createProject` → 403 untuk peran `app-user`; boleh untuk `app-manager`/admin. `createMyPrivateProject` boleh untuk semua user. Proyek baru berisi 4 kolom bawaan: Backlog, Ready, Work in progress, Done |
| Tanggal jatuh tempo | `createTask(date_due)` menerima teks `Y-m-d` / `Y-m-d H:i` (dan format tanggal pengguna, default `m/d/Y` — "01/10/2026" terbaca **10 Januari**!). Angka epoch → `result:false` (ditolak validator). Teks dibaca di **zona waktu aktif** (`getTimezone`, default `UTC`). Skill selalu mengirim `Y-m-d H:i` setelah konversi dari WIB/WITA/WIT ke zona server; diverifikasi benar untuk server UTC dan Asia/Jakarta |
| Baca tugas | `getAllTasks(project_id, status_id=1)` → field epoch `date_due`, `date_moved` (diperbarui saat pindah kolom), `column_id`, `owner_id`, `swimlane_id`, `is_active` |
| Pindah | `moveTaskPosition(project_id, task_id, column_id, position, swimlane_id)` → `true`; memperbarui `date_moved` |
| Penugasan | `getAssignableUsers(project_id)` → objek `{"<id>": "<nama atau username>"}`; `createTask(owner_id)` bukan anggota → `false` |
| Bocoran data | `getMe` mengembalikan field sensitif (`api_access_token`, `twofactor_secret`) → skill hanya mengambil id/username/nama/peran, tidak pernah mencetak objek mentah |

## 5. Audit keamanan (Tahap 3)
- Tidak ada kode pihak ketiga yang disertakan; `scripts/kanboard.py` ditulis dari nol (Python stdlib: urllib, json, base64, ipaddress).
- Kontrol: daftar izin metode (baca: getVersion, getTimezone, getMe, getMyProjects, getAllProjects, getProjectById, getColumns, getAllTasks, getTask, getAssignableUsers, getActiveSwimlanes; tulis: createProject, createMyPrivateProject, updateColumn, addColumn, createTask, moveTaskPosition — **tanpa** remove*/close*/user); konfirmasi `--ya`; allowlist host (loopback bebas, host lain harus didaftarkan pemilik, internet wajib https); redirect ditolak; proxy dilewati untuk host lokal/privat; batas jawaban 20 MB; timeout; token dari file 600/ENV, disamarkan di pesan galat; kode keluar 8 untuk hasil tulis tak pasti.
- Uji regresi 106 cek dengan server tiruan (termasuk metode terlarang, redirect, timeout/5xx saat tulis, token tidak pernah muncul di keluaran).
