## Audit keamanan (Tahap 3)
- Tidak menjalankan script pihak ketiga. Yang dijalankan: image resmi `listmonk/listmonk:6.2.0` (mirror `mirror.gcr.io`, label revision `ef0a758`) + `postgres:17`, jaringan Docker tertutup, port hanya `127.0.0.1`.
- Bawaan yang diperhatikan: kata sandi admin bawaan pada Compose contoh & port terbuka ke semua jaringan → panduan mengganti sandi, mengikat port ke `127.0.0.1`, dan memakai **pengguna API berperan terbatas** (tanpa izin pengaturan/pengguna).
- Token API pengguna tipe `api` tampil sekali saat dibuat; skill tidak pernah mencetaknya.

## Temuan API (diuji nyata pada v6.2.0, 29 Sep 2026)
- Auth: `Authorization: token <pengguna>:<token>` (pengguna tipe API dibuat dari Settings > Users, atau `POST /api/users`). `/api/health` juga butuh auth.
- Impor: `POST /api/import/subscribers` multipart (`params` JSON: `mode`, `subscription_status`, `delim`, `lists`, `overwrite` + `file`); status via `GET`. Impor status `unconfirmed` **tidak** mengirim email opt-in otomatis; kirim lewat `POST /api/subscribers/{id}/optin`.
- `POST /api/subscribers` ke list opt-in *double* langsung mengirim email konfirmasi (bawaan berbahasa Inggris → ganti bahasa ke Indonesia di Settings).
- `POST /api/campaigns/{id}/test` hanya menerima alamat yang **sudah ada sebagai pelanggan** ("No known subscribers to test").
- Izin `subscribers:sql_query` diperlukan untuk parameter `query`; skill memakai `search` (tanpa izin SQL).
- Status jadwal: `scheduled` (butuh `send_at`); pembatalan jadwal = kembalikan ke `draft` (`cancelled` hanya untuk kampanye aktif).
- Pelacakan klik hanya untuk tautan berakhiran `@TrackLink`; buka = piksel `px.png`.
- Hitung `subscriber_count` di `/api/lists` berasal dari cache; hitungan pasti lewat `GET /api/subscribers?list_id=&subscription_status=`.

## SMTP (bahan panduan; harga bisa berubah — cek halaman resmi)
- Amazon SES: ±US$0,10–0,16 per 1.000 email; kredit gratis AWS baru hingga US$200 (https://aws.amazon.com/ses/pricing/, dicek 29 Sep 2026); akun baru biasanya mulai di mode sandbox sehingga perlu diajukan ke produksi (tidak dikonfirmasi di halaman harga — verifikasi di dokumentasi SES).
- Brevo: paket gratis ±300 email/hari (sumber sekunder: ringkasan pihak ketiga hasil pencarian 29 Sep 2026; cek https://www.brevo.com/pricing/); verifikasi domain (SPF/DKIM) & akun bisa ditinjau manual.
- Verifikasi domain (SPF, DKIM, DMARC) berlaku untuk semua penyedia.
