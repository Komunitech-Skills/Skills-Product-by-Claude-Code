Batas spec: `name` 1–64 karakter `[a-z0-9-]`, tidak diawali/diakhiri `-`, sama dengan folder; `description` 1–1024 karakter. Claude Code memotong description di 1.536 karakter. OpenClaw: nilai frontmatter satu baris; beri tanda kutip bila nilai mengandung `:` di posisi yang bisa membingungkan YAML.

**Kesimpulan untuk penulisan skill:** path file pendukung ditulis relatif terhadap folder SKILL.md, tanpa placeholder khusus platform; script Python (bukan .sh saja).

**Perlu dicek ulang:** path Windows & reload di Cursor, path Windows native OpenClaw.
