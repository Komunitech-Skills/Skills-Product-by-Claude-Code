## Audit keamanan (Tahap 3) — yang dibaca sebelum dijalankan
- `docker-compose.yml` (v3.4.0): 2 image resmi (`ghcr.io/umami-software/umami:latest`, `postgres:15-alpine`); port `3000:3000` terbuka ke semua jaringan dan `APP_SECRET`/sandi DB contoh → panduan mengubah ke `127.0.0.1`, nilai acak, versi dikunci.
- `Dockerfile`, `scripts/start-docker.sh`, `scripts/check-db.js` (migrasi Prisma), `scripts/update-tracker.js` (hanya mengganti endpoint di `script.js` bila ENV diisi): tidak ada unduhan skrip saat menyala.
- Telemetri: `/api/scripts/telemetry` memasang piksel versi ke server pembuat kecuali `DISABLE_TELEMETRY` → panduan mengisi `DISABLE_TELEMETRY: 1`.
- Kode lacak (`src/tracker/index.ts`): tanpa cookie; `localStorage` hanya dibaca untuk tanda opt-out `umami.disabled`; menghormati `data-do-not-track`.
- Database: tabel `session`/`website_event` tidak menyimpan IP maupun user-agent (diperiksa `\d session` di instance uji). ID sesi = hash(website, IP, UA, garam bulanan).
- Kunci API (3.4.0): awalan `umami_`, disimpan sebagai hash; diblokir untuk `/api/me/password`, `/api/me/api-keys`, `/api/2fa`, `/api/auth`, `/api/users`, `/api/admin`. **Catatan:** jawaban `/api/me` memuat kunci/token yang dipakai → skill tidak pernah mencetaknya.

## Alternatif yang dipertimbangkan
Plausible (AGPL, ClickHouse — berat), PostHog OSS (berat), Matomo (GPL, PHP/MySQL; tidak dicek mendalam). Umami dipilih: MIT, ringan (1 app + Postgres), tanpa cookie, UI bahasa Indonesia tersedia.
