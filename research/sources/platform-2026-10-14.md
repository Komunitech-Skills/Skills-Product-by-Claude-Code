## Cuplikan sumber (≤2 baris masing-masing)

**Cursor** — https://cursor.com/docs/context/skills (2026-10-14)  
> `~/.cursor/skills/` | User-level (global) on the local machine  
> Cursor does not copy your local `~/.cursor/skills/` … to Cloud Agents … use project skills from the repo or bake skills into the worker image.

**Claude Code** — https://docs.anthropic.com/en/docs/claude-code/skills (2026-10-14)  
> Personal | `~/.claude/skills/<name>/SKILL.md` | All your projects on this machine  
> Project | `.claude/skills/<name>/SKILL.md` | Sessions in this repository

**OpenAI Codex** — https://developers.openai.com/codex/skills (2026-10-14)  
> `$HOME/.agents/skills` | Any skills checked into the user's personal folder.  
> Each skill is a directory with a `SKILL.md` file … must include `name` and `description`.

**OpenClaw** — `node_modules/openclaw/docs/tools/skills.md` & `docs/cli/skills.md` (versi terpasang 2026.9.8, 2026-10-14)  
> Add `--global` to install into the shared `~/.openclaw/skills` directory  
> `openclaw skills install ./path/to/skill --as custom-name`

## Cursor Cloud (VM Akun C, 2026-10-14)

- Skill bawaan Cursor ada di `~/.cursor/skills-cursor/` (bukan folder pembeli).
- Skill user global `~/.cursor/skills/` **belum ada** di VM sampai dibuat; skill pembeli untuk uji C21 harus disalin ke **`.cursor/skills/` di repo** atau `~/.cursor/skills/` lalu disinkronkan (Settings → Agents → Sync Skills) bila dipakai Cloud Agent.
- Agent run ini memuat skill dari `<available_skills>` (termasuk path `~/.cursor/skills-cursor/…`).
