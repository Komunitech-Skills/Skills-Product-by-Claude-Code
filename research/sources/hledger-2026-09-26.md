## Keputusan
**DIKURASI sebagai perangkat lunak pendamping (tidak didistribusikan).**
- Komunitech **tidak menyalin, memodifikasi, atau mendistribusikan** kode atau binary hledger. Pembeli mengunduh sendiri dari sumber resmi mengikuti `docs/panduan-hledger.md` (dengan langkah cek checksum).
- Produk Komunitech = skill `skills/hledger-usaha` (script Python standar yang menjalankan hledger sebagai program luar dan menulis data dalam format jurnal/aturan CSV hledger) + panduan + template akun Indonesia. Semuanya **karya orisinal Komunitech**, ditulis dari nol berdasarkan dokumentasi publik tentang format data. Tidak ada teks/contoh dokumentasi hledger yang disalin.
- Karena tidak ada distribusi hledger, kewajiban GPL (menyertakan lisensi & kode sumber) tidak berlaku untuk paket Komunitech. Bila kelak Komunitech ingin **menyertakan** binary hledger di installer/jasa setup, wajib menyertakan teks GPL-3.0, tautan/tawaran kode sumber versi persis, dan tidak memodifikasinya (lihat §4 riset pengganti SaaS) → minta persetujuan pemilik dulu.
- Nama "hledger" dipakai hanya sebagai penyebut kompatibilitas, dengan keterangan "tidak berafiliasi" (keputusan pemilik 2026-09-26 tentang merek pihak ketiga).
- Jalur produk: `skills/hledger-usaha` (katalog: orisinal, Proprietary Komunitech, ecer usulan Rp 149.000, draft).

## Audit keamanan (Tahap 3)
- Binary hanya diunduh dari rilis resmi, checksum dicocokkan, dijalankan di scratchpad (tidak dipasang ke sistem).
- Tidak ada perintah pasang lewat pipa skrip dari internet di panduan; alternatif winget/Homebrew disebut sesuai hledger.org, ditandai "belum dicoba Komunitech".
- hledger-web tidak punya autentikasi → panduan & skill mewajibkan hanya `127.0.0.1` dan `--allow=view`; dicoba: bawaan memang hanya mendengarkan 127.0.0.1.
- `hledger setup` menghubungi internet untuk mengecek versi terbaru; skill tidak memakai perintah itu.
