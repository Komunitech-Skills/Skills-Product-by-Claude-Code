# Ceklis Serah-Terima — Solusi VIP Riset Kripto & Keuangan Pribadi

Paket ini untuk member VIP (akses semua skill). Satu halaman. **Jangan tulis saldo, alamat dompet, nomor rekening, seed phrase, atau API key
di ceklis ini** — hanya status ya/tidak.

## Prasyarat
- [ ] OpenClaw terpasang & bisa diajak chat biasa.
- [ ] Mesin Gateway dipilih: ☐ laptop/PC jam tertentu ☐ mini PC 24 jam ☐ VPS sendiri
      ☐ jasa setup Komunitech.
- [ ] Member paham: bila mesin mati/tidur, notifikasi **tidak terkirim**.

## Pemasangan skill
- [ ] 6 skill terpasang: `karyawan-ai-mulai`, `cek-privasi-openclaw`, `atur-keuangan-pribadi`,
      `notebook-riset-lokal`, `asisten-tulis-riset`, dan **[VIP]** `pantau-pasar-kripto`.
- [ ] `karyawan-ai-mulai` dijalankan sekali, ada 1 hasil nyata.
- [ ] `cek-privasi-openclaw` dijalankan.
- [ ] Open Notebook (untuk `notebook-riset-lokal`, opsional): ☐ dipasang sendiri ☐ jasa setup
      ☐ tidak dipakai.

## Kanal
- [ ] Bot Telegram tersambung, pairing disetujui, ID chat dicatat di catatan pribadi.
- [ ] **Bila memakai WhatsApp:** nomor **terpisah**, hanya ke diri sendiri, persetujuan risiko
      **tertulis**, `dmPolicy` = `allowlist`, `allowFrom` hanya nomor member.

## Batas tegas (wajib dicentang semua)
- [ ] Member paham **tidak ada auto-trading**, tidak ada rekomendasi beli/jual/tahan, tidak ada
      sinyal atau target harga, dan tidak ada pembuatan bot trading di paket ini.
- [ ] Member sudah membaca bagian "Kenapa auto-trading tidak disediakan" di `PANDUAN.md`.
- [ ] Tidak ada API key/secret exchange, seed phrase, atau kunci privat yang pernah ditempel ke
      chat. Bila pernah: sudah **dicabut (revoke)** dan diganti.
- [ ] Member paham ini **bukan nasihat investasi**; kripto berisiko tinggi, modal bisa hilang.
- [ ] Member hanya memakai bursa/penyelenggara **terdaftar/berizin** dan tahu cara mengecek
      daftar resmi di ojk.go.id; tahu kontak **OJK 157** / Satgas PASTI untuk dugaan penipuan.
- [ ] Ringkasan/notifikasi selalu memuat disclaimer; data basi/gagal diberi label, tidak dikarang.

## Privasi
- [ ] Jurnal trading, `kripto/`, dan catatan keuangan disimpan hanya di komputer member,
      dicadangkan berkala.
- [ ] Member tahu isi yang diproses dikirim ke penyedia model AI pilihannya (kecuali model
      lokal) dan tahu cara menjalankan `cek-privasi-openclaw` kapan saja.
- [ ] Tidak ada broadcast atau pengiriman ke pihak lain lewat OpenClaw.
